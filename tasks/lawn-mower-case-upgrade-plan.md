目标：把「先规划 → 并发执行」这套流程再跑一次在 `robot-lawn-mower` 这一页上。**不新增第六条案例**——该案例已于 `70b4988` 交付并集成（规划见 [lawn-mower-case-plan.md](lawn-mower-case-plan.md)），再生成一条只会在 `cases[]` 里产生内容重复。本轮改为对现有这一页做有证据支撑的升级。

## 本轮为什么有活可干：三处实测出来的缺陷

不是找补，三处都是跑脚本或亲眼看图取到的证据：

### 1. 插画中心主体读作「相机」，且越界用色

把现有 SVG 渲染成 PNG 实际查看：深色圆角机身正中一枚大圆刀盘 = 镜头，机身左上两个小方块 = 取景器与快门，整体读作一台相机；三叶刀盘又近似辐射标志。上一轮规划已经警觉过「侧视割草机像公交车」，改成俯视后问题只是从公交车挪到了相机，没有真正解决。

同时，脚本比对四幅插画用色发现：

| 插画 | 用色数 | 结果 |
| --- | --- | --- |
| eureka | 7 | ✓ |
| smart-litter-box | 7 | ✓ |
| **robot-lawn-mower** | **8** | **⚠ 越界 `#0d2029`** |
| womens-athleisure | 7 | ✓ |

四幅里只有它越界。前一轮规划的验收标准明确写了「插画未引入既有色板之外的颜色」，但该标准从未被脚本执行，所以违规照样发布。

### 2. 文案缺了「社媒」这一面

脚本比对三个社媒案例的覆盖：

| 案例 | 具名平台 | 用户素材 |
| --- | --- | --- |
| eureka | 有 | 无 |
| smart-litter-box | 无 | 有 |
| **robot-lawn-mower** | **无** | **无** |

两处真实缺口：

- **形态与平台维度缺席。** 这是一条**社交媒体**内容营销案例，但全文只说「各平台后台」，从未触及这个品类的内容形态分化：安装与建图要长视频才讲得清，割草演示是短视频的料，而坡度、草种、气候的地域差异把答疑推向本地语言的社群与论坛。安装复杂这一事实必然导出形态分工，现有文案讲了前者、漏了后者。
- **提了问题没给答案。** 文案把「草坪不可迁移，一块草坪上成立的演示换一块未必成立」作为核心约束提出，却从没写出这个约束的内容答案：**草坪运不过来，但车主自家就有**——车主素材是覆盖多种真实庭院的唯一现实路径。这是逻辑缺环，不是风格问题。

### 3. 色板规则从未被机器执行

`scripts/verify-site.cjs` 逐轮生长（上一轮刚加了「每页恰好一张插画」和「页面无 undefined」两条），但色板这条每轮写进规划、每轮靠人眼，这轮它漏掉了一个真实违规。应当固化成断言。

## 内容边界（沿用，不放宽）

不编造客户品牌（本案例以品类立题，全文不出现公司名、型号、商标）；**不编造任何数据指标**（不写播放量、粉丝数、互动率、转化率、GMV、百分比）；不编造平台的具体政策条款或审核结论。提到平台形态时，说的是**这个品类的内容形态如何分工**，不是某个客户在某平台的投放结果。

## 并发分轨

| 轨 | 范围 | 独占文件 |
| --- | --- | --- |
| A 重画插画 | `robot-lawn-mower` 行内 SVG：主体必须读作割草机而非相机；清除第八色 `#0d2029` | `scripts/case-art.cjs` |

| C 色板断言 | 给案例详情页的行内 SVG 加色板白名单断言 | `scripts/verify-site.cjs` |

三轨文件互斥，均不运行 `npm run build`，集成构建由主线程统一执行。

**A 与 C 有依赖但方向一致**：C 加的断言会卡住 A 当前的越界色，A 正是要清除它；两轨并发没有冲突，集成时一起验。
