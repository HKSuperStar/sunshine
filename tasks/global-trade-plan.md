# 出海外贸业务规划

定位：SunShine 为有产品和供应链能力的企业提供外贸增长与 Agent 协同服务。依据现有公司战略与 JoyLink 案例，不暗示自营商品商城、进出口代理资质或保证订单。

信息架构：维持六项主导航，新增 `/global-trade/` 与 `/en/global-trade/`，归属产品。首页、产品页、案例页和联系页均提供入口。

专页设计：深蓝金色 Hero、业务阶段与交付物、Agent 与人工协同、适用行业、合作方式、JoyLink 案例入口、FAQ、外贸需求表。

需求表：企业、邮箱、产品、目标市场、阶段、主要问题。数据只在浏览器生成可复制文本，不虚报发送；无真实联系方式不编造电话邮箱。

并行任务：内容线程编写双语服务文案；交互线程实现外贸表单；主线程负责页面模板、视觉、导航入口与验证。

验收：中英文独立路由，所有入口正确，表单生成包含全部字段，移动端无溢出，原站栏目和14行业保留。构建通过后同步 GitHub、生产部署并检查 URL。
